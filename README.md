# Smart-Adaptive-Streetlight-Controller
This project designs and implements a light-sensing control system with an MBED LPC1768 board, an LDR sensor and four LEDs. The LDR module monitors ambient light intensity and sends an analogue signal to the microcontroller, which then drives four LEDs via current-limiting resistors. The system displays automated lighting control, in which LED brightness or activation changes dynamically in response to ambient illumination. This concept integrates sensors and actuators in embedded systems, providing practical applications for energy-efficient lighting and smart home control.
